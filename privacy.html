Privacy Policy — G.A.D.F

Last updated: September 2026

G.A.D.F ("gadf") is a personal AI assistant built and used by a single individual (the "owner"). It is not a public product or service offered to third parties. This policy explains what data gadf handles and how, for transparency and to satisfy the requirements of the APIs it connects to.

What data gadf stores

gadf stores, in a private database accessible only to the owner:

  • Chat messages and conversation history
  • Long-term memory summaries derived from conversations
  • Identity facts the owner has told gadf about themselves
  • Google OAuth tokens (access and refresh tokens), if Google is connected
  • Coding task instructions submitted for the local coding agent to execute

Google user data

If the owner connects their Google account, gadf requests access to Google Drive and Google Calendar solely to perform actions the owner explicitly asks for in conversation — searching, reading, creating, or deleting files, and listing, creating, updating, or deleting calendar events. This access is used only to fulfill those requests, in real time, at the owner's direction.

gadf's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never sold, and is never used for advertising or shared with any third party except the AI model providers described below, strictly to generate a response to the owner's own request.

Third-party processing

To generate responses, message content is sent to Anthropic's Claude API and, for memory retrieval, to Google's Generative Language (Gemini) embedding API. These providers process the data solely to return a result to gadf and are not used for any other purpose by this app.

Data storage and security

All data is stored in a Supabase (PostgreSQL) database protected by row-level security, scoped so that only the authenticated owner's account can read or write it. No other users exist on this system.

Data retention and deletion

Data is retained until the owner deletes it. The owner can revoke gadf's access to their Google account at any time via Google Account permissions, which immediately stops any further Drive/Calendar access.
